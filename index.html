Build Memory 第一步

给每个业务员工配一个 AI 工作伙伴

不是先建知识图谱，而是先让 Agent 跟人一起工作，在协作中自然累积上下文。

传统思路：先建库再用

花 6 个月整理历史数据、构建知识图谱、标注实体关系。

问题：工程量巨大、数据过时快、业务团队感知不到价值。

我的思路：边用边建

Day 1 给投放专员配一个 AI Agent，跟他一起做投放决策。

每次协作自动沉淀：决策背景、选择理由、执行结果。

W1
员工 + AI Agent 一起工作
Agent 辅助分析数据、生成投放方案，员工做最终决策
W4
Agent 开始"记住"这个员工的偏好和经验
协作上下文自动结构化为 Decision Trace，不需要人工标注
M3
组织级记忆自然形成
多个员工的 Agent 记忆汇聚 → Knowledge Graph 自底向上生长，而非自顶向下设计

核心理念：记忆不是一次性工程项目，而是在人机协作中持续生长的活体系统。
